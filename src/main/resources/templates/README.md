# Excel Templates Guide

## Структура шаблонов

Поместите ваши Excel шаблоны в эту директорию:
- `template1.xlsx` - для отчетов Substitute и Fitting (горизонтальная ориентация)
- `template2.xlsx` - для отчета Hydrotest (вертикальная ориентация)

## Требования к шаблонам

### Общие требования

Каждый шаблон должен содержать:
1. **Рабочий лист** (первый лист) - на нем будут печататься данные
2. **Лист "Templates"** - лист с шаблонами шапок и строк

### Именованные ячейки и диапазоны

Все именованные диапазоны создаются через: Формулы → Диспетчер имен → Создать

#### Для template1.xlsx (горизонтальная ориентация)

**Именованные ячейки:**
- `name` - ячейка для названия детали (например, A1 на рабочем листе)
- `sum` - ячейка с формулой суммы (на листе Templates)

**Именованные диапазоны на листе "Templates":**
- `substitute_header` - диапазон с шапкой таблицы Substitute (например, A1:D2)
- `substitute_row` - диапазон с одной строкой-шаблоном для данных (например, A3:D3)
- `fitting_header` - диапазон с шапкой таблицы Fitting (например, A5:D6)
- `fitting_row` - диапазон с одной строкой-шаблоном для данных (например, A7:D7)

**Пример структуры листа "Templates":**
```
Строка 1-2: Шапка таблицы Substitute (объединенные ячейки, форматирование)
Строка 3: Строка-шаблон для данных Substitute

Строка 5-6: Шапка таблицы Fitting
Строка 7: Строка-шаблон для данных Fitting

Строка 9: Ячейка sum с формулой (например, =SUM(B2:B100))
```

#### Для template2.xlsx (вертикальная ориентация)

**Именованные ячейки:**
- `name` - ячейка для названия детали (например, A1 на рабочем листе)
- `start_cell` - начальная ячейка для вертикального заполнения данных (например, A5)

**Примечание:** Для вертикального шаблона не нужны отдельные шапки и строки на листе Templates,
так как данные заполняются непосредственно в существующую структуру.

## Как создать именованный диапазон в Excel

1. Выделите нужные ячейки
2. Перейдите: Формулы → Определенные имена → Присвоить имя
3. Введите имя (например, `substitute_header`)
4. Убедитесь, что в поле "Область" выбрана "Книга"
5. Нажмите OK

## Стили и форматирование

- Все стили, границы, заливка и форматирование ячеек будут скопированы из шаблонов
- Объединенные ячейки в шапках будут корректно скопированы
- Ширина колонок из шаблона будет применена к рабочему листу

## Формулы

- В ячейке `sum` можно использовать любую формулу Excel
- При копировании формула будет автоматически скорректирована
- После генерации отчета все формулы будут пересчитаны

## Пример использования в коде

```java
// Горизонтальный отчет с одной таблицей
TablePrintRequest table = TablePrintRequest.builder()
    .tableName("Деталь ABC-123")
    .headerRangeName("substitute_header")
    .rowRangeName("substitute_row")
    .data(dataFromDatabase)
    .columnKeys(Arrays.asList("col1", "col2", "col3"))
    .includeSumRow(true)
    .build();

byte[] report = excelReportService.generateHorizontalReport(
    "templates/template1.xlsx",
    Collections.singletonList(table),
    "Templates"
);

// Вертикальный отчет
byte[] report = excelReportService.generateVerticalReport(
    "templates/template2.xlsx",
    "Деталь XYZ-456",
    dataFromDatabase,
    Arrays.asList("col1", "col2", "col3"),
    "start_cell",
    "Templates"
);
```
